# Evvy-BV-UTI
Data and code from Whang et al. "Large-scale metagenomic characterization of the vaginal microbiome and uropathogens in women with recent bacterial vaginosis and urinary tract infections." https://www.nature.com/articles/s41467-026-78217-1 

The previously available pre-print "Vaginal Microbiome in Women Recently Experiencing BV & UTI" can be found: https://www.biorxiv.org/content/10.1101/2025.11.27.690987v1.full
